# Angom - bola hanamora ny fiainanao

A Streamlit app that helps students manage their daily money
and reach a savings goal.

## Features

- Set a goal (name, amount, duration in days)
- Enter the money received each day
- Add daily necessities and see the rest per day
- Progress bar toward the goal

## Run locally

    pip install -r requirements.txt
    streamlit run project_app.py
